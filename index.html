One-time Firebase setup (5 minutes, free)
  1. Go to console.firebase.google.com and create a new project (any name).
  2. In the project, click Firestore Database → Create database → choose Start in test mode → pick any region.
  3. Go to Project Settings (gear icon) → Your apps → click the </> (web) icon → register the app.
  4. Copy the firebaseConfig object shown and paste it into this file, replacing the placeholder at the bottom of the <script> section (search for PASTE YOUR FIREBASE CONFIG HERE).
  5. Save the file, push to GitHub, enable GitHub Pages (Settings → Pages → Deploy from main branch), and share the URL.

Sharing scores: Only you need to update golfer scores in the Golfer scores tab — everyone else sees updates live.
Pool rules

Each participant selects up to 5 golfers. Their best 2 scores count toward their pool total. Golfers who miss the cut or withdraw are excluded. Lowest total score wins.
